能力

像人一样听，像助理一样办事

边听边说，靠语义判断什么时候该接话、该等待、该停下来。

01

自然的对话节奏

你表示认同时它继续说，你打断时立刻停下；你在思考时它等你说完。

02

分得清谁在跟它说话

多人场景下只回应说给它听的那句，不插嘴旁人的闲聊。

03

记得自己说到哪儿

被打断后从实际说到的那个字接着讲，不从头再来。

04

边听边译

你说话的同时就在翻译，不必等整段说完才开始。

05

边说边办事

需要实时信息就去查，复杂任务放后台，合适的时候再把结果带回来。

06

看得见，也会主动

支持摄像头与屏幕共享，约定好规则后，条件满足它会主动开口。

实现说明

一条 WebSocket，三种数据流

浏览器无法在 WebSocket 握手时携带 Authorization 头，API Key 也不能出现在前端。所以本项目在中间加了一层本地中继：鉴权、清洗、转发都由它完成。

前端 浏览器

麦克风 16 kHz PCM、摄像头/屏幕 JPEG、播放回执

本地中继 FastAPI 服务

注入 Bearer 密钥、校验指令、限制帧大小、统计指标

上游 MOSS-Live

全双工语音模型：转写、回答、语音、打断

  • AudioWorklet48 kHz 采集实时重采样到 16 kHz PCM S16LE，20 ms 一帧上行
  • WebAudio48 kHz 下行音频分块入队播放，按实际播放完成回执，可即时打断
  • tagged-v10x00 音频 / 0x01 摄像头 / 0x02 屏幕，同一条连接复用
  • JPEG 1 FPS画面按帧发送，摄像头长边 640 px、屏幕 1024 px，质量 0.8
